# UK AI/ML Job Search Agent

A self-learning agent that searches UK job portals and company career pages daily for AI/ML Engineer and Data Scientist roles, ranks them against my CV and preferences, and delivers a top-15 digest.

## Status
🚧 In development

## Setup
1. `python3 -m venv venv` then activate it
2. `pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and fill in API keys
